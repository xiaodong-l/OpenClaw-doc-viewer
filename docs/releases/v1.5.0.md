# Release v1.5.0 - Automation

**Release Date:** 2026-03-14  
**Commit:** `48cfbfc`  
**Type:** Minor Release

---

## 🤖 Overview

This release introduces automation features to reduce maintenance overhead. The highlight is Dependabot auto-merge for minor and patch updates, along with automated PR assignment and release workflows.

---

## ✨ New Features

### Dependabot Auto-Merge
- Automatic merging of minor updates
- Automatic merging of patch updates
- Major updates require manual review
- Configurable auto-merge rules

### Auto-Assign Action
- Automatic PR assignment based on:
  - File paths
  - Labels
  - Author
- Configurable assignment rules
- Fallback assignees

### Release Automation
- Automated GitHub release creation
- Changelog generation
- Version badge updates
- Release notes templates

---

## ⚙️ Configuration

### Dependabot Configuration

```yaml
# .github/dependabot.yml
version: 2
updates:
  - package-ecosystem: "npm"
    directory: "/workspace/backend"
    schedule:
      interval: "daily"
    open-pull-requests-limit: 10
    auto-merge: true  # Minor and patch only
    
  - package-ecosystem: "github-actions"
    directory: "/"
    schedule:
      interval: "daily"
```

### Auto-Merge Rules

```yaml
# .github/auto-merge.yml
- match:
    dependency-type: "production"
    update-type: "version-update:semver-minor"
- match:
    dependency-type: "production"
    update-type: "version-update:semver-patch"
```

### Auto-Assign Configuration

```yaml
# .github/auto-assign.yml
addAssignees: true
assignees:
  - xiaodong-l
numberOfAssignees: 1
```
