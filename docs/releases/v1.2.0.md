**Release Date:** 2026-03-13  
**Commit:** `874eb48`  
**Type:** Minor Release

## 👤 Overview

This release introduces personalization and organization features, allowing users to customize their experience and manage their reading preferences. The highlight is the addition of user collections, reading history, and dark mode.

---

## ✨ New Features

### Avatar Upload
- Custom profile pictures
- File size validation (max 5MB)
- Multiple format support (PNG, JPG, GIF)
- Automatic thumbnail generation

### Document Collections
- Bookmark favorite documents
- Organize into custom collections
- Drag-and-drop organization
- Batch operations (move, delete)

### Reading History
- Automatic tracking of viewed documents
- Chronological history list
- Quick resume from last read
- History cleanup utilities

### Document Sharing
- Generate shareable links
- Configurable expiration (1h, 24h, 7d, 30d, never)
- View count tracking
- One-click copy to clipboard

### Dark Mode
- Complete theme switching
- System preference detection
- Persistent user preference
- Smooth transition animations

## 🔧 Technical Changes

### New Database Tables
```sql
-- User profiles
CREATE TABLE user_profiles (
  id INTEGER PRIMARY KEY,
  user_id INTEGER,
  avatar_path TEXT,
  theme_preference TEXT DEFAULT 'light'
);

-- Collections
CREATE TABLE collections (
  id INTEGER PRIMARY KEY,
  user_id INTEGER,
  name TEXT,
  created_at DATETIME
);

-- Reading history
CREATE TABLE reading_history (
  id INTEGER PRIMARY KEY,
  user_id INTEGER,
  document_path TEXT,
  viewed_at DATETIME
);

-- Share links
CREATE TABLE share_links (
  id INTEGER PRIMARY KEY,
  document_path TEXT,
  token TEXT UNIQUE,
  expires_at DATETIME
);
```

### New API Endpoints
- `POST /api/user/avatar` - Upload avatar
- `GET /api/collections` - List collections
- `POST /api/collections` - Create collection
- `GET /api/history` - Get reading history
- `POST /api/share` - Generate share link
