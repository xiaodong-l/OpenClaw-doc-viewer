**Type:** Major Release (Initial)

## 🎉 Overview

The first stable release of OpenClaw Doc Viewer Community Edition. This release establishes the foundation for a modern, open-source documentation viewer with essential features for browsing and managing Markdown documentation.

---

## ✨ Key Features

### Directory Tree Navigation
- Expandable folder structure
- Real-time file system reflection
- Click-to-navigate interface

### Markdown Rendering
- Full Markdown specification support
- Syntax highlighting for code blocks
- Table of contents generation
- Image and asset embedding

### Authentication & Authorization
- JWT-based authentication
- Role-based access control:
  - **Admin:** Full system access
  - **Editor:** Content modification
  - **Viewer:** Read-only access

### Real-Time Updates
- File change detection
- Automatic content refresh
- No manual reload required

### Basic Statistics
- Document count tracking
- User activity monitoring
- System health dashboard

---

## 📦 Installation

### Prerequisites

- Node.js >= 18.0.0
- npm >= 9.0.0

### Quick Start

```bash
# Clone repository
git clone https://github.com/xiaodong-l/OpenClaw-doc-viewer.git
cd OpenClaw-doc-viewer

# Install dependencies
npm install

# Start development server
npm run dev

# Or start production server
npm start
```

### Default Configuration

| Setting | Value |
|---------|-------|
| Backend Port | 3000 |
| Frontend Port | 3001 |
| Auth | JWT (default secret) |
| Data Source | Local file system |

## 🔧 Technical Stack

### Backend
- **Runtime:** Node.js 18+
- **Framework:** Fastify 4.x
- **Auth:** @fastify/jwt
- **CORS:** @fastify/cors

### Frontend
- **Framework:** Vue 3.x
- **Build Tool:** Vite 5.x
- **UI:** Element Plus (basic)
- **Router:** Vue Router 4.x

### Data
- **Storage:** File system (JSON)
- **Search:** Basic file scanner
