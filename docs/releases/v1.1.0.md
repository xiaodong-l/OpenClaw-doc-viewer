# Release v1.1.0 - Search & Navigation

**Release Date:** 2026-03-12  
**Commit:** `9a891cb`  
**Type:** Minor Release

---

## 🔍 Overview

This release focuses on discoverability and user experience improvements. The highlight is the integration of full-text search using FlexSearch, enabling users to quickly find content across 1800+ indexed documents.

---

## ✨ New Features

### Full-Text Search
- **Engine:** FlexSearch integration
- **Index Size:** 1800+ documents
- **Performance:** Sub-second search results
- **Features:**
  - Highlighting in results
  - Fuzzy matching
  - Multi-field search

### Directory Tree Lazy Loading
- Load directories on demand
- Reduced initial load time
- Better performance for large repositories

### Breadcrumb Navigation
- Clear navigation path display
- Click-to-navigate breadcrumbs
- Overflow handling on mobile

### Responsive Design
- Mobile-friendly interface
- Adaptive layouts
- Touch-optimized controls

### Reading Progress
- Table of contents panel
- Reading progress bar
- Scroll-synced highlighting
