# 📦 v1.3.0 发布说明

**版本**: v1.3.0  
**发布日期**: 2026-03-13  
**上一版本**: v1.2.0  
**下一版本**: v2.0.0 (规划中)

---

## 🎉 版本亮点

v1.3.0 聚焦于**用户体验优化**与**协作功能增强**，新增了三大核心功能：

1. **🔗 分享链接公开页面** - 无需登录即可查看分享的文档
2. **📦 批量收藏管理** - 高效管理收藏夹和文档
3. **💬 文档评论功能** - 支持用户对文档进行评论和讨论

---

## 🚀 新增功能

### 1. 分享链接公开页面 🔗

**问题**: v1.2.0 虽然支持创建分享链接，但接收方需要登录才能查看。

**解决方案**: 新增公开分享页面，任何人拿到分享链接即可查看文档，无需登录。

**功能详情**:
- ✅ 公开访问 `/share/:token` 页面
- ✅ 支持 Markdown 渲染和代码高亮
- ✅ 显示文档目录 (TOC)
- ✅ 支持暗黑模式
- ✅ 自动记录访问计数
- ✅ 过期和访问上限检查

**API 变更**:
```
NEW: GET  /api/v1/shares/:token/public      # 获取分享信息 (无需认证)
NEW: GET  /api/v1/shares/:token/document    # 获取文档内容 (无需认证)
```

**新增组件**:
- `ShareView.vue` - 公开分享页面组件

**使用示例**:
```
https://your-domain.com:YOUR_PORT/share/abc123def456
```

---

### 2. 批量收藏管理 📦

**问题**: v1.2.0 只能逐个删除或移动文档，效率低下。

**解决方案**: 新增批量操作功能，支持全选、多选、批量删除和移动。

**功能详情**:
- ✅ 批量选择文档 (全选/单选)
- ✅ 批量删除收藏文档
- ✅ 批量移动文档到其他收藏夹
- ✅ 批量删除收藏夹
- ✅ 操作确认对话框
- ✅ 操作结果反馈

**API 变更**:
```
NEW: POST /api/v1/collections/:id/docs/batch-delete   # 批量删除文档
NEW: POST /api/v1/collections/:id/docs/batch-move     # 批量移动文档
NEW: POST /api/v1/collections/batch-delete            # 批量删除收藏夹
```

**新增组件**:
- `BatchActions.vue` - 批量操作工具栏组件

**更新组件**:
- `DocumentCollections.vue` - 支持批量选择模式

---

### 3. 文档评论功能 💬

**问题**: 用户无法对文档进行讨论和交流。

**解决方案**: 新增完整的评论系统，支持评论、回复、点赞、编辑和删除。

**功能详情**:
- ✅ 发表文档评论
- ✅ 回复其他用户的评论
- ✅ 点赞/取消点赞评论
- ✅ 编辑自己的评论
- ✅ 删除评论 (作者或管理员)
- ✅ Markdown 格式支持
- ✅ 评论树形展示
- ✅ 实时评论计数

**API 变更**:
```
NEW: GET    /api/v1/comments?path=xxx          # 获取评论列表
NEW: GET    /api/v1/comments/stats?path=xxx    # 获取评论统计
NEW: POST   /api/v1/comments                   # 创建评论
NEW: PUT    /api/v1/comments/:id               # 更新评论
NEW: DELETE /api/v1/comments/:id               # 删除评论
NEW: POST   /api/v1/comments/:id/like          # 点赞评论
```

**新增服务**:
- `commentService.js` - 评论数据管理服务

**新增路由**:
- `comments.js` - 评论 API 路由

**新增组件**:
- `DocumentComments.vue` - 评论列表和输入组件

**数据模型**:
```typescript
interface Comment {
  id: string
  documentPath: string
  userId: string
  userName: string
  userAvatar?: string
  content: string
  parentId?: string
  likes: number
  likedBy: string[]
  createdAt: string
  updatedAt: string
}
```

## ⚠️ 注意事项

### 评论功能
- 评论功能需要用户登录才能使用
- 管理员可以删除任何评论
- 评论数据存储在 `workspace/backend/data/comments.json`
- 建议定期备份评论数据

### 分享功能
- 公开分享页面无需认证，请谨慎分享敏感文档
- 分享链接可以设置过期时间和访问次数限制
- 建议定期检查分享统计

### 批量操作
- 批量删除操作不可恢复，请谨慎操作
- 批量移动会自动去重，避免重复文档

## 📈 升级指南

### 从 v1.2.0 升级

```bash
# 1. 备份现有数据
cp workspace/backend/data/users.json workspace/backend/data/users.json.bak
cp workspace/backend/data/comments.json workspace/backend/data/comments.json.bak 2>/dev/null || echo '{}' > workspace/backend/data/comments.json

# 2. 拉取最新代码
git pull origin main

# 3. 安装依赖 (如有更新)
cd workspace/backend && npm install
cd ../frontend && npm install

# 4. 重建前端
cd workspace/frontend && npm run build

# 5. 重启服务
pm2 restart doc-viewer-api

# 6. 验证服务
curl https://your-domain.com:YOUR_PORT/health
```

### 配置文件变更

无需修改配置文件，所有新功能自动启用。

### 数据库变更

- 新增 `comments.json` 数据文件 (自动创建)
- `users.json` 结构无变更
