## 📦 新增功能详情

### 1. 用户头像上传 (Sprint 1)

**组件**: `AvatarUpload.vue`  
**API**: `POST/GET/DELETE /api/v1/user/avatar`

- 支持 JPG/PNG/GIF 格式
- 文件大小限制 5MB
- 自动裁剪缩放至 200x200
- 实时预览
- 一键更换/删除

**使用场景**:
- 用户个性化设置
- 团队识别

---

### 2. 文档收藏功能 (Sprint 2)

**组件**: `DocumentCollections.vue`  
**API**: `/api/v1/collections/*`

- 创建/编辑/删除收藏夹
- 添加/移除文档到收藏夹
- 手风琴式折叠展示
- 文档计数徽章
- 点击直接跳转文档

**API 列表**:
```
GET    /api/v1/collections              # 获取收藏列表
POST   /api/v1/collections              # 创建收藏夹
PUT    /api/v1/collections/:id          # 更新收藏夹
DELETE /api/v1/collections/:id          # 删除收藏夹
POST   /api/v1/collections/:id/documents       # 添加文档
DELETE /api/v1/collections/:id/documents/:path # 移除文档
GET    /api/v1/collections/:id/documents       # 获取文档列表
```

**使用场景**:
- 收藏常用文档
- 按项目/主题分类整理
- 快速访问工作资料

---

### 3. 阅读历史记录 (Sprint 3)

**组件**: `ReadingHistory.vue`  
**API**: `/api/v1/user/history/*`

- 自动记录阅读历史
- 保留最近 100 条记录
- 相对时间显示 (5 分钟前/3 小时前)
- 清空全部/删除单条
- 点击跳转文档

**API 列表**:
```
GET    /api/v1/user/history           # 获取历史记录
POST   /api/v1/user/history           # 添加记录
DELETE /api/v1/user/history           # 清空历史
DELETE /api/v1/user/history/:path     # 删除单条
```

**使用场景**:
- 找回之前看过的文档
- 追踪阅读进度
- 审计文档访问

---

### 4. 文档分享功能 (Sprint 4)

**组件**: `DocumentShare.vue`  
**API**: `/api/v1/shares/*`

- 生成唯一分享令牌
- 权限控制 (只读/可评论)
- 有效期设置 (1/7/30 天/永久)
- 访问次数限制
- 访问统计追踪
- 一键复制链接

**API 列表**:
```
GET    /api/v1/shares              # 获取分享列表
POST   /api/v1/shares              # 创建分享
GET    /api/v1/shares/:token       # 获取分享详情 (公开)
DELETE /api/v1/shares/:id          # 删除分享
GET    /api/v1/shares/:id/stats    # 获取统计
```

**使用场景**:
- 与团队成员分享文档
- 外部协作
- 临时文档分发
- 访问控制

---

### 5. 暗黑模式完善 (Sprint 5)

**组件**: `ThemeSwitcher.vue`, `useDarkMode.js`  
**样式**: 完整 Element Plus 暗黑主题

- 浅色/深色/自动 三模式
- 系统主题自动跟随
- 定时切换 (日落/日出时间)
- 用户偏好持久化 (localStorage)
- 完整组件样式覆盖
- 0.3s 平滑过渡动画

**设置选项**:
- 跟随系统
- 定时切换 (可配置日落/日出时间)
- 手动切换

**使用场景**:
- 夜间舒适阅读
- 减少眼睛疲劳
- 个性化界面偏好

## 🔧 技术改进

- 新增 3 个组件 (`DocumentCollections`, `ReadingHistory`, `DocumentShare`, `ThemeSwitcher`)

- 完善暗黑模式 CSS 变量体系

### 后端

- 新增 2 个路由模块 (`collections.js`, `shares.js`)

## 🚀 升级指南

### 从 v1.1.0 升级到 v1.2.0

```bash
# 1. 拉取最新代码
cd /path/to/your/home/.openclaw/projects/doc-viewer
git pull origin main

# 2. 安装依赖 (如有更新)
cd workspace/backend && npm install
cd ../frontend && npm install

# 3. 重新构建
cd frontend && npm run build

# 4. 重启服务
pm2 restart doc-viewer-api

# 5. 验证版本
curl http://localhost:3000/api/v1/health
```
