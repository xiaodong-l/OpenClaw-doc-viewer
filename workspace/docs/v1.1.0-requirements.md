## 🔍 功能 1: 全文搜索功能

### 需求描述

实现快速、准确的文档全文搜索，支持关键词高亮、搜索结果分页、搜索建议等功能。

### 用户故事

```
作为 用户
我想要 搜索文档内容
以便于 快速找到我需要的信息
```

### 功能详情

#### 1.1 搜索界面

**位置**: 顶部导航栏搜索框 + 独立搜索页面

**交互流程**:
```
用户输入关键词 → 显示搜索建议 → 点击搜索/回车 → 显示搜索结果
```

**UI 组件**:
- 搜索输入框 (带清空按钮)
- 搜索建议下拉列表
- 搜索结果列表
- 分页控件
- 搜索过滤器 (按目录、文件类型、时间)

#### 1.2 搜索功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **关键词搜索** | 支持单/多关键词搜索 | P0 |
| **搜索结果高亮** | 在摘要和原文中高亮关键词 | P0 |
| **搜索建议** | 输入时显示相关建议 | P0 |
| **最近搜索** | 记录并显示最近搜索历史 | P1 |
| **高级搜索** | 按目录、时间、文件类型过滤 | P1 |
| **搜索结果导出** | 导出搜索结果列表 | P2 |

#### 1.3 搜索 API

**端点**: `GET /api/v1/search`

**请求参数**:
```typescript
{
  q: string,           // 搜索关键词 (必需)
  limit?: number,      // 每页数量 (默认 20)
  offset?: number,     // 偏移量 (默认 0)
  path?: string,       // 限定目录
  type?: 'file' | 'dir', // 文件类型
  timeRange?: {        // 时间范围
    from: string,
    to: string
  }
}
```

**响应格式**:
```typescript
{
  success: boolean,
  data: {
    query: string,
    total: number,
    limit: number,
    offset: number,
    results: Array<{
      path: string,
      name: string,
      title: string,
      excerpt: string,      // 摘要 (含高亮)
      score: number,        // 相关性评分
      highlights: string[], // 高亮关键词
      updatedAt: string
    }>
  },
  meta: {
    timestamp: string,
    version: string
  }
}
```

#### 1.4 技术实现

**后端**:
```javascript
// services/searchIndex.js
import FlexSearch from 'flexsearch'

export class SearchIndex {
  constructor() {
    this.index = new FlexSearch.Document({
      tokenize: 'forward',
      charset: 'latin:extra',
      optimize: true,
      document: {
        id: 'id',
        index: ['title', 'content', 'excerpt'],
        store: ['title', 'path', 'name', 'updatedAt']
      }
    })
  }

  async search(query, options = {}) {
    const results = this.index.search(query, {
      limit: options.limit || 20,
      suggest: true
    })
    
    return this.formatResults(results, query)
  }

  async add(document) {
    this.index.add(document)
  }

  async remove(id) {
    this.index.remove(id)
  }
}
```

**前端**:
```vue
<!-- components/SearchBox.vue -->
<template>
  <div class="search-box">
    <el-input
      v-model="query"
      placeholder="搜索文档..."
      clearable
      @input="handleInput"
      @keyup.enter="handleSearch"
    >
      <template #prefix>
        <el-icon><Search /></el-icon>
      </template>
    </el-input>
    
    <!-- 搜索建议 -->
    <div v-if="suggestions.length" class="suggestions">
      <div
        v-for="item in suggestions"
        :key="item.id"
        class="suggestion-item"
        @click="selectSuggestion(item)"
      >
        {{ item.title }}
      </div>
    </div>
  </div>
</template>

<script setup>
import { ref, computed, debounce } from 'vue'
import api from '@/api'

const query = ref('')
const suggestions = ref([])

const handleInput = debounce(async (value) => {
  if (value.length < 2) {
    suggestions.value = []
    return
  }
  
  const { data } = await api.getSuggestions(value)
  suggestions.value = data
}, 300)

const handleSearch = () => {
  if (query.value.trim()) {
    router.push({ path: '/search', query: { q: query.value } })
  }
}
</script>
```

```vue
<!-- components/Breadcrumb.vue -->
<template>
  <el-breadcrumb separator="/">
    <el-breadcrumb-item :to="{ path: '/' }">
      <el-icon><HomeFilled /></el-icon>
      首页
    </el-breadcrumb-item>
    
    <el-breadcrumb-item
      v-for="(part, index) in pathParts"
      :key="index"
      :to="getBreadcrumbPath(index)"
    >
      {{ part }}
    </el-breadcrumb-item>
  </el-breadcrumb>
</template>

<script setup>
import { computed } from 'vue'
import { useRoute } from 'vue-router'

const route = useRoute()

const currentPath = computed(() => route.query.path)

const pathParts = computed(() => {
  if (!currentPath.value) return []
  return currentPath.value.split('/').filter(Boolean)
})

const getBreadcrumbPath = (index) => {
  const path = '/' + pathParts.value.slice(0, index + 1).join('/')
  return { path: '/document', query: { path } }
}
</script>
```

#### 4.3 技术实现

```vue
<!-- composables/useResponsive.js -->
import { ref, onMounted, onUnmounted } from 'vue'

export function useResponsive() {
  const width = ref(window.innerWidth)
  const height = ref(window.innerHeight)
  
  const isMobile = computed(() => width.value < 768)
  const isTablet = computed(() => width.value >= 768 && width.value < 1024)
  const isDesktop = computed(() => width.value >= 1024)
  
  const handleResize = () => {
    width.value = window.innerWidth
    height.value = window.innerHeight
  }
  
  onMounted(() => {
    window.addEventListener('resize', handleResize)
  })
  
  onUnmounted(() => {
    window.removeEventListener('resize', handleResize)
  })
  
  return {
    width,
    height,
    isMobile,
    isTablet,
    isDesktop
  }
}
```

    <div class="preview-content" :style="{ fontSize: fontSize + 'px' }">
      <!-- Markdown 预览 -->
      <div
        v-if="file.type === 'markdown'"
        class="markdown-body"
        :class="{ 'dark-mode': darkMode }"
        v-html="renderedHtml"
      />
      
      <!-- 代码预览 -->
      <div
        v-else-if="file.type === 'code'"
        class="code-preview"
      >
        <pre><code :class="languageClass">{{ file.content }}</code></pre>
      </div>
      
      <!-- 图片预览 -->
      <div v-else-if="file.type === 'image'" class="image-preview">
        <el-image
          :src="imageUrl"
          :preview-src-list="[imageUrl]"
          fit="contain"
        />
      </div>
      
      <!-- 纯文本预览 -->
      <div v-else class="text-preview">
        <pre>{{ file.content }}</pre>
      </div>

<script setup>
import { ref, computed, onMounted, onUnmounted } from 'vue'
import { useRoute } from 'vue-router'
import markdownIt from 'markdown-it'
import hljs from 'highlight.js'

const route = useRoute()
const file = ref(null)
const toc = ref([])
const fontSize = ref(16)
const darkMode = ref(false)
const tocVisible = ref(false)
const progress = ref(0)

const md = markdownIt({
  html: true,
  linkify: true,
  typographer: true,
  highlight: (str, lang) => {
    if (lang && hljs.getLanguage(lang)) {
      return hljs.highlight(str, { language: lang }).value
    }
    return ''
  }
})

const renderedHtml = computed(() => {
  if (file.value?.type !== 'markdown') return ''
  
  const html = md.render(file.value.content)
  
  // 提取目录
  toc.value = extractToc(file.value.content)
  
  return html
})

const languageClass = computed(() => {
  const ext = file.value?.name.split('.').pop()
  return `language-${ext}`
})

// 阅读进度
const handleScroll = () => {
  const scrollTop = window.scrollY
  const docHeight = document.documentElement.scrollHeight - window.innerHeight
  progress.value = (scrollTop / docHeight) * 100
}

onMounted(() => {
  window.addEventListener('scroll', handleScroll)
})

onUnmounted(() => {
  window.removeEventListener('scroll', handleScroll)
})

const toggleToc = () => {
  tocVisible.value = !tocVisible.value
}

const zoomIn = () => {
  fontSize.value = Math.min(fontSize.value + 2, 24)
}

const zoomOut = () => {
  fontSize.value = Math.max(fontSize.value - 2, 12)
}
</script>
