## 6️⃣ 开放问题讨论

### 问题 1: 定价策略

**讨论:**
- 按用户数？按文档量？混合模式？
- 社区版 vs 企业版边界？

**决策:**
```
社区版 (免费):
- 最多 5 用户
- 最多 1,000 文档
- 基础功能

专业版 ($10/用户/月):
- 最多 50 用户
- 最多 10,000 文档
- 高级功能 (评论、分享、收藏)

企业版 ($30/用户/月):
- 无限用户
- 无限文档
- 全部功能 (SSO、审计、权限)
```

### 问题 2: 部署模式

**讨论:**
- SaaS only? 支持私有化部署？

**决策:**
```
Phase 1: SaaS only (快速上市)
Phase 2: 私有化部署 (企业客户需求)
  - Docker Compose (小型部署)
  - Kubernetes (大型部署)
  - 许可证管理 (年费 20% 维护费)
```

### 问题 3: 升级路径

**讨论:**
- v1.x 到 v2.0.0 如何迁移？

**决策:**
```
数据迁移:
- 用户数据：自动迁移 (脚本)
- 文档数据：兼容 (无变更)
- 配置数据：手动迁移 (文档指导)

升级窗口:
- 2026-Q2: 提前通知
- 2026-Q3: 正式升级
- 2026-Q4: v1.x EOL
```

### 问题 4: API 兼容性

**讨论:**
- 如何保证向后兼容？

**决策:**
```
API 版本策略:
- /api/v1/* : 保持兼容 (至少 12 个月)
- /api/v2/* : v2.0.0 新 API
- 废弃通知: 提前 6 个月通知
- 迁移指南: 提供详细文档
```

### 问题 5: 社区版边界

**讨论:**
- 哪些功能保留给社区版？

**决策:**
```
社区版包含:
✅ 文档查看/搜索
✅ 基础收藏/分享
✅ 评论功能
✅ 暗黑模式
❌ SSO 集成
❌ 审计日志
❌ 高级权限
❌ 企业集成
```
