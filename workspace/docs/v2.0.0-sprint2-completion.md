## 🏗️ 数据模型

### 权限角色

| 角色 | 权限 |
|------|------|
| `owner` | 查看、编辑、管理、删除 |
| `editor` | 查看、编辑 |
| `viewer` | 查看 |

### 权限操作

| 操作 | 说明 |
|------|------|
| `view` | 查看文档 |
| `edit` | 编辑文档 |
| `manage` | 管理权限 |
| `delete` | 删除文档 |

### 数据库表

```sql
-- 文档权限表
document_permissions
  - id, document_path, user_id, role
  - granted_by, granted_at, expires_at

-- 用户组表
user_groups
  - id, name, description
  - created_by, created_at, updated_at

-- 组成员表
user_group_members
  - id, group_id, user_id, joined_at

-- 组权限表
group_permissions
  - id, document_path, group_id, role
  - granted_by, granted_at, expires_at

-- 审计日志表
permission_audit_logs
  - id, document_path, user_id, action
  - old_role, new_role, changed_by, changed_at
```
