## 📦 安装与升级

### 全新安装

```bash
# 1. 克隆仓库
git clone https://github.com/xiaodong-l/doc-viewer.git
cd doc-viewer

# 2. 切换到 v2.0.0
git checkout v2.0.0

# 3. 安装依赖
cd workspace/backend && npm install
cd ../frontend && npm install

# 4. 构建前端
cd ../frontend && npm run build

# 5. 配置环境变量
cd ../backend && cp .env.example .env
# 编辑 .env 配置数据库/Redis 等

# 6. 启动服务
cd ..
pm2 start config/pm2.config.js --env production
```

### 从 v1.3.1 升级

```bash
# 1. 备份数据
cp -r workspace/backend/data /backup/data-$(date +%Y%m%d)

# 2. 拉取新版本
git fetch --tags
git checkout v2.0.0

# 3. 安装新依赖
cd workspace/backend && npm install
cd ../frontend && npm install && npm run build

# 4. 数据库迁移 (如适用)
# 参考 workspace/docs/UPGRADE-v2.0.0.md

# 5. 重启服务
pm2 restart doc-viewer-api
```
