## 🏗️ 技术设计

### 数据库设计

#### 文档版本表
```sql
CREATE TABLE document_versions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  document_id UUID REFERENCES documents(id),
  version_number INTEGER NOT NULL,
  content_hash VARCHAR(64) NOT NULL,
  content_snapshot_path VARCHAR(2048),
  change_summary VARCHAR(1024),
  change_type VARCHAR(50), -- create, update, restore
  created_by UUID REFERENCES users(id),
  created_at TIMESTAMP DEFAULT NOW(),
  
  UNIQUE(document_id, version_number)
);

CREATE INDEX idx_versions_doc ON document_versions(document_id);
CREATE INDEX idx_versions_created ON document_versions(created_at DESC);
```

#### 文档锁表
```sql
CREATE TABLE document_locks (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  document_path VARCHAR(2048) UNIQUE NOT NULL,
  locked_by UUID REFERENCES users(id),
  locked_at TIMESTAMP DEFAULT NOW(),
  expires_at TIMESTAMP,
  reason TEXT,
  
  UNIQUE(document_path)
);

CREATE INDEX idx_locks_path ON document_locks(document_path);
CREATE INDEX idx_locks_user ON document_locks(locked_by);
```

#### 通知表
```sql
CREATE TABLE notifications (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  type VARCHAR(50) NOT NULL, -- comment, mention, share, version
  title VARCHAR(255) NOT NULL,
  content TEXT,
  link VARCHAR(512),
  is_read BOOLEAN DEFAULT FALSE,
  read_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_notifications_user ON notifications(user_id);
CREATE INDEX idx_notifications_read ON notifications(is_read);
```

### API 设计

#### 版本管理 API
```javascript
// 获取版本历史
GET /api/v2/versions?path=/docs/readme.md

// 获取特定版本
GET /api/v2/versions/:versionId

// 创建新版本
POST /api/v2/versions
{
  "documentPath": "/docs/readme.md",
  "changeSummary": "更新安装说明",
  "content": "..."
}

// 版本对比
GET /api/v2/versions/:fromId/diff/:toId

// 回滚到版本
POST /api/v2/versions/:versionId/rollback
```

#### 文档锁定 API
```javascript
// 锁定文档
POST /api/v2/locks
{
  "documentPath": "/docs/readme.md",
  "reason": "正在进行重大修改",
  "duration": 3600
}

// 释放锁定
DELETE /api/v2/locks/:documentPath

// 获取锁定状态
GET /api/v2/locks/:documentPath
```

#### 通知 API
```javascript
// 获取通知列表
GET /api/v2/notifications?unread=true

// 标记为已读
PATCH /api/v2/notifications/:id/read

// 批量标记已读
POST /api/v2/notifications/read-all

// 通知设置
GET /api/v2/notification-settings
PUT /api/v2/notification-settings
```
