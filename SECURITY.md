# Security Policy

For detailed security information, please see [.github/SECURITY.md](.github/SECURITY.md).

## Quick Summary

### Reporting a Vulnerability

**DO NOT** report security vulnerabilities through public GitHub issues.

Instead, please report them via email at: **security@openclaw.ai**

### Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | ✅ Yes             |
| 1.2.x   | ✅ Yes             |
| 1.1.x   | ❌ No              |
| 1.0.x   | ❌ No              |

### Security Best Practices

1. **Change Default Password** - Always change the default admin password
2. **Use Strong JWT Secret** - Generate a random, strong secret
3. **Enable HTTPS** - Use HTTPS in production
4. **Keep Updated** - Regularly update to the latest version

For more details, see [.github/SECURITY.md](.github/SECURITY.md).
